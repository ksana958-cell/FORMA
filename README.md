# FORMA DARK — Telegram Mini App для BotHost (2.2)

Перенос версии FORMA 2.1 DARK EDITION с Cloudflare на **Node.js + SQLite + приватные файлы** в BotHost. Две основные вкладки: тренировки и питание. Сохранены тёмная тема, упражнения, подсказки, журнал подходов, календарь, рацион на неделю, фото питания с подтверждением КБЖУ, избранные блюда, измерения тела и фотопрогресс.

## Запуск

Проект готов к публикации через **GitHub → BotHost**. Используйте **кастомный Dockerfile** (включён) с Node.js 24, поскольку SQLite использует встроенный модуль `node:sqlite` без npm-пакетов. Порт задаётся переменной `PORT`, сервер слушает `0.0.0.0`.

В BotHost файлы данных сохраняются в `/app/data`:

- `/app/data/forma.sqlite` и файлы журнала SQLite WAL;
- `/app/data/private-photos/<Telegram ID>/...` — фотографии, которые нельзя открыть по прямому URL;
- `/app/data/backups` — резервные копии, созданные вручную.

**Откройте `ИНСТРУКЦИЯ_BOTHOST.md` и выполните шаги по порядку.**

## Основные файлы

- `app.js` — HTTP-сервер, SQLite, закрытые фото, напоминания, автоматическая привязка бота;
- `src/worker.js` — проверка подписи Telegram, API тренировок/питания и фотораспознавания;
- `public/` — исходный интерфейс FORMA 2.1 DARK;
- `schema.sql` — таблицы SQLite (создаются автоматически);
- `Dockerfile` — Node.js 24;
- `scripts/test-bothost.mjs` — локальная проверка API;
- `scripts/setup-telegram.mjs` — ручная переустановка вебхука, если понадобится;
- `scripts/backup.mjs` — резервная копия базы + фотографий;
- `FORMA_preview.html` — автономный HTML-предпросмотр без сервера и Telegram;
- `РАЦИОН_7_ДНЕЙ.md` — ориентировочное меню.

## Переменные окружения

| Имя | Назначение |
| --- | --- |
| `BOT_TOKEN` | Секретный токен нового бота от @BotFather; никогда не помещайте в GitHub |
| `WEBHOOK_SECRET` | Случайная строка 16–256 символов (буквы/цифры/`_`/`-`) |
| `PUBLIC_BASE_URL` | HTTPS-адрес включённого домена BotHost, без завершающего слэша |
| `OWNER_TELEGRAM_ID` | Числовой ID владельца. Если не знаете, сначала отправьте боту `/start`, после подключения webhook он сообщит ID |
| `OFF_CONTACT` | Контактный email для Open Food Facts, только если нужен поиск по штрихкоду |
| `OPENAI_API_KEY` | **Необязательно**: платное распознавание еды по фото |
| `OPENAI_MODEL` | Необязательно, по умолчанию `gpt-4.1-mini` |
| `PORT` | BotHost передаёт сам, обычно 3000 |
| `DATA_DIR` | Для BotHost использовать `/app/data` — задаётся Dockerfile |

Webhook и кнопка меню Mini App регистрируются **автоматически** при старте, если указаны токен, секрет и HTTPS-домен. Из соображений безопасности сервер сверяет подпись `Telegram.WebApp.initData` и пропускает только `OWNER_TELEGRAM_ID`.

## Локальная проверка

Нужен Node.js >=22.13, лучше 24:

```bash
npm test
```

Для локальной демоверсии откройте `FORMA_preview.html` в браузере. В автономном режиме **нет синхронизации, настоящего ИИ и уведомлений Telegram**.

## Ограничения

- Проект проверен автоматическими API-тестами, но реальное развёртывание в вашем BotHost и вход с реального Telegram бота нужно проверить после настройки.
- Telegram-напоминания работают при **непрерывно запущенном контейнере**. Если хостинг останавливает приложение при простое, напоминания могут запаздывать или не прийти.
- Распознавание фото — **приблизительная оценка**, пользователь подтверждает значения перед добавлением в дневник.
- Библиотека упражнений содержит схемы и текст, внешние видео можно добавить позже, соблюдая права на использование.
- Фотографии и журнал питания содержат чувствительную личную информацию. Контролируйте доступ к BotHost, GitHub и резервным копиям.

## Что проверить после публикации

1. `https://ваш-домен/api/health` возвращает `ok: true`, `databaseConfigured: true`.
2. Бот отвечает на `/start` и открывает приложение.
3. Внутри Telegram сохраняются подходы, блюда, вес и талия; после перезапуска записи остаются.
4. Фото прогресса доступны только в личном интерфейсе.
5. Включённые напоминания приходят в Пн/Ср/Пт при заданном часовом поясе.
