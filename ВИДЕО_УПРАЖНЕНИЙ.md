## Управление

- GIF повторяется при открытии упражнения. «Остановить GIF» возвращает первый кадр; «Воспроизвести GIF» начинает показ заново. Настройка остановки сохраняется при отметке подходов в текущем запуске приложения.
- Если в системе включено уменьшение движения, GIF сначала неподвижен и запускается кнопкой.
- MP4 запускается вручную; доступны встроенные пауза, перемотка и звук. При закрытии карточки воспроизведение останавливается.
- Если медиа недоступно, можно продолжить тренировку по резервной схеме и тексту.

## Соответствие домашнему варианту

`oneRow.gif` показывает скамью под рукой и коленом. Под роликом пояснён вариант с обеими стопами на полу и свободной рукой на устойчивой поверхности. `calfRaise.gif` показан без стены — стену можно использовать для равновесия. В `tricepsOH.gif` одна гантель удерживается горизонтально двумя руками. Эти различия подписаны в карточках.

## Замена демонстрации

Добавь разрешённый для использования файл в `public/media/`. В `public/videos.js` обнови нужный элемент `FORMA_MEDIA_MAP`: `src`, `type` (`gif` или `video`), `poster` и размеры. В `poster` укажи первый кадр PNG или JPG. При смене содержимого меняй параметр `?v=` в ссылке, чтобы браузер не показывал старую версию.

Для обычного MP4 можно также задать строку в `FORMA_VIDEO_MAP` — она имеет приоритет для совместимости с прежними версиями. Это не меняет саму программу тренировок.

После изменения файлов выполни `npm run preview:build`: сборщик заново встроит локальные медиа в `FORMA_preview.html`. Для новой загрузки на BotHost нужны и обновлённые исходники, и папка `public/media/`.
